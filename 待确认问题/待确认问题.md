### 时序

- 按下开关 EC 收到开关信号 延时发送高低高给桥 PWRBTN#脚
- 桥发出高电平的 SLP_S5# SLP_S4# SLP_S3# SLP_A# SLP_LAN#
- SLP_S4# SLP_S5# 控制产生 内存主供电 1.2V 内存 VPP 供电 2.5V VCCST 供电 1V
- SLP_S3# 控制产生二级电压 3.3V 二级电压 5V 总线供电 0.95V VCCPLL_OC 1.2V VCCPLL 1v
- VCCST 供电正常后，产生 VCCST_PWRGD 信号给 CPU，控制输出 VCCSA 供电 1.05V 和 CPU 核心供电
- 各供电正常后，产生 CPU 供电的开启信号，控制输出 VCCSA 供电 1.05V 和 CPU 核心供电
- 各供电正常后，桥的 24M 晶振起振，PG 汇总先后产生 PCH_PWROK 和 SYS_PWROK 给桥
- 桥收到 PCH_PWROK 后，100~300 桥 通过 SPI 总线读取 BIOS 中的 ME
- 桥发出各路时钟
- 桥发出 PROCPWRGD 给 CPU 的 PROCPWRGD 脚
- 桥延时发出平台复位 PLTRST# 3.3V 桥再发出 CPU 复位 PLTRST_PROC# 送给 CPU 的 RESET# 脚
- CPU 发出 SVID 波形给 CPU 供电芯片 调整（开启） CPU 核心电压
- CPU 供电 正常，并得到复位后，通过 DMI 总线到桥，桥再通过 SPI 总线读取 BIOS，开始自检
- 自检到内存时，桥通过 SMBUS 读取内存的 SPD 信息后，桥发出内存复位 DRAM_RESET#
- CPU 再次发出 SVID 波形给 CPU 供电芯片，控制产生集显供电 VCCGT
