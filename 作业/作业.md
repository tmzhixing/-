## PWM 维修流程

# <span style="color:blue">一、PWM 电路波形</span>

1、 3V / 5V 电感前端波形

- 高频脉冲直流电
- 正常峰峰值 25V 左右 使用 10V 一格测量
  2、 3V / 5V 电感后端波形
- 平滑的直流电 对应 3V 5V
- 使用双通道一起抓，可以通过判断哪一路先掉电，判断哪一路有故障
  3、 （装上两路上管） 测 3V / 5V 上管 G 极波形
- 上管 25V 左右峰峰值
- 下管 5V 左右峰峰值
- 500 微秒
- 正常下管先工作，且不会同时导通

4、 （不装两路上管） 3V / 5V 上管 G 极波形

- 基定压 由 线性 5V 通过一个二极管提供

5、 (装上管) 双通道同时抓取上下管 G 极波形

-

6、 3V / 5V 线性

7、 （去掉 3V 上管） 测 5V 电感前端和后端波形

8、 双通道同时测量 3.3V 的 EN 信号 与 3.3V 电感后端波形对比
