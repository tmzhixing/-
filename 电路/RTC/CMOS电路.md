# RTC/CMOS 电路。

一、RTC/CMOS 电路
作用：RTC 控制系统时间，CMOS 存储时间及 BIOS 设置。
RTC：实时时钟控制器。
CMOS：CMOS RAM 存储器。
CMOS/RTC 都是集成在南桥内部的模块。

1、电路核心
南桥(南桥内部 RTC/CMOS 模块)
2、主要电压及信号。
1、供电 VCCRTC: RTC/CMOS 的供电，大约 3V 左右。 2.时钟 32.768KHZ：由 32.768 晶振产生。 3.复位 RTCRST#、SRTCRST#,正常工作时必须为高电平(3V)，如果为低电平 RTC/CMOS 复位(初始化清零)。

RC 延时电路一般用于复位电路中

- 台式机与笔记本 RTC/CMOS 电路不同点：
  1、台式机手动复位使用 CMOS 跳针，笔记本手动复位使用接地的焊点。
  2、台式机 CMOS 电池通常不能被充电，笔记本 CMOS 电池在某些主板上可以充电。
  3、笔记本某些内置电池型号取消小电池，直接大电池供电。

RTC/CMOS 在主板上赵线：
1、确定出发点目的地(搞清楚从哪里开始找，找到哪去？)
例如：RTC/CMOS 电路：出发点(电池正极)--目的地（南桥）。
出发点出发，找到目的地结束！如果找别的地方一律为旁路，旁路不考虑。

电池正极--电阻--二极管--南桥(VCCRTC) RTC 供电
电池正极--电阻--二极管--电阻--跳针--南桥(RTCRST#) 复位信号
电池正极--电阻--二极管--电阻--南桥（SRTCRST#） 复位信号
32.768KHZ 晶振--南桥
2、找到电容，电容为旁路，不管电容！
3、遇到过线孔，在反面找线！
4、遇到障碍物，在对应的其他方向找线！
5、边找线边画图，分析是否正确！

- RTC/CMOS 电路损坏后现象:
  1、系统时间及 BIOS 设置在关机拔电源后不能存储！
  通常为纽扣电池没电或电池的电无法提供到 RTC/CMOS 电路。
  2、系统时间过快或过慢！
  通常为 32.768 晶振损坏，更换晶振及相连谐振电容，不行换南桥
  3、导致开机电路不工作！(不加电)
  检查 RTC 电路时，不要连接电源（安装纽扣电池即可）
  *1.检查 VCCRTC
  *测量 RTC/CMOS 电路中二极管负极，正常为 3V 左右（不能低于 2.6V）
  *2.检查 32.768KHZ 晶振
  *判断晶振是否起振
  *1.测量晶振两端电压，正常为分别有 0.2V-1V 左右电压并且两脚有电压差。
  *2.示波器测量有波形！
  如果晶振不起振，更换晶振及相连谐振电容，不行换南桥
  \*3.检查 RTCRST#、SRTCRST#
  测量 CMOS 测试点（RTCRST），正常为高电平(3V 左右)。如果不正常（为低电平），通常为跳针连接的贴片电容或南桥坏！SRTCRST#某些双桥的主板没有此信号，需要查看电路图找到！
