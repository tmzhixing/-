## PWM 电路中相位的作用

在 PWM（脉宽调制）电路中，大多数人首先关注的是频率和占空比。但相位是一个常被忽略却极其关键的参数，它的作用在不同应用场景下截然不同。

我们可以从三个层面来理解相位在 PWM 中的作用：

1. 在单路 PWM 中：相位决定“触发时刻”
   对于单个 PWM 信号，相位指的是该信号波形相对于某个基准时间（如时钟零点）的偏移量（通常以度或时间表示）。

作用：实现精确延时触发。比如在数字电源中，当检测到过流信号后，需要等待几个微秒再关闭 PWM 以避开尖峰干扰，这时调节相位就是调节这个等待时间。

作用：实现可控硅（SCR）移相触发。在交流调压中，通过改变 PWM（这里指脉冲串）相对于交流电过零点的相位，来决定可控硅的导通角，从而调节灯泡亮度或电机转速。

2. 在多路 PWM 中：相位决定“错峰”与“重叠”
   这是相位最重要的应用场景。当系统中有两路或以上 PWM（如同桥臂、多相电源）时，相位差决定了它们之间的时序关系。

交错并联（Interleaving）——减少纹波：在多相同步降压电路中，各路 PWM 的相位会均匀错开（如 4 路 PWM 相位分别设为 0°、90°、180°、270°）。这会让各路电流纹波在输入端相互抵消，从而大幅减小输入电容的纹波电流，并提高有效开关频率，减少 EMI（电磁干扰）滤波器的体积。

避免直通短路——死区插入：在半桥或全桥电路中，上下管 PWM 信号必须互补。为了防止上下管同时导通导致短路，相位调节用于精确控制下管的开启滞后于上管关闭的时间——这个滞后时间就是死区时间。它的作用是保障功率管的安全。

同步整流（Sync Rectification）——最优效率：在 LLC 谐振变换器等拓扑中，次级同步整流管的 PWM 驱动信号需要相对于初级侧精确移相，以确保其刚好在体二极管导通之前开启。相位调节在此的作用是最大化转换效率，防止电流反向倒灌。

3. 在电机控制（FOC）中：相位决定“力矩”与“转速”
   在无刷直流电机或永磁同步电机的矢量控制中，PWM 的相位具有物理层面的决定作用。

相位超前角（Advance Angle）：PWM 电压矢量相对于电机反电动势（BEMF）的相位差，直接决定了转子的受力方向。如果相位超前过小，电机重载时会失步或堵转；如果相位超前过大，虽然高速性能好，但铜损增加、效率下降。调节此相位，实质是调节定子磁场与转子磁场的夹角，从而在“最大扭矩输出”和“最高转速”之间取得平衡。

4. 在信号解调（数字通信）中：相位决定“信息”
   如果 PWM 作为载波传递模拟信息（如 PPM，脉冲位置调制），那么占空比固定，相位（即脉冲前沿或后沿的位置）的变化就代表了具体的数值信息。在此场景下，相位的作用就是承载数据。

特别警示：容易被忽略的“相位抖动”
在工程实践中，相位不仅是主动调节的参数，也是噪声的体现。PWM 的相位抖动（Jitter）——即开关边沿在时间轴上的随机提前或滞后——会直接导致：

在 AD 采样中产生调制噪声，降低信噪比（SNR）；

在音频功放中产生刺耳的杂音；

在精密控制中引起低速抖动。

因此，高性能 PWM 控制器（如 TI 的 HRPWM）往往具备高精度移相和边沿定位功能，就是为精确控制相位而设计的。

### PWM 供电方式的介绍

脉冲宽度调制简称脉宽调制。PWM 信号是数字的，在给定的任何时刻，满幅值的直流供电要么完全有，要么完全无。电压或电流源是以一种通或断的重复脉冲序列被加到模拟负载上去的。通的时候即是直流供电被加到负载上的时候，断的时候即是供电被断开的时候。

- PWM 供电方式组成：PWM 芯片 场管 电感 滤波电容
- BUCK：直流降压变换电路 SMPS 开关电源也是指这样的供电方式

### 自举升压电路

PWM 电源中，由于电源芯片本身对上管的驱动能力有限，几乎所有的芯片都采用了自举升压电路来提高驱动能力。自举升压脚名字一般为 BOOT 、BST、BOOST、VBST 等。
BOOT 脚：启动脚、自举升压脚、基电压脚。
自举升压的目的：驱动上管完全导通。
自举升压异常导致的故障：上管未完全导通，容易烧上管！
工作过程简述：
1.19V 给上管芯片供电 2.芯片内部稳压器把 19V 转成 5V 线性电压
3.5V 线性通过二极管给 BOOT 脚供电，因为自举电容右端为 0V，左端连接 BOOT 脚，电容充电 5V
4.T1 时间，BOOT 给 UGATE 供电，驱动上管导通，上管 G 极 5V，S 极 0V，沟道完全打开 5.上管导通后产生的电压送到电容的右侧，因电容两端电压不能突变的特性，BOOT 脚电压会始终保持比电容右端高 5V，直到上管完全导通产生 19V，BOOT 会达到 24V

### PWM 电路的电压电流检测

- 输出电压调整，电压电流检测
- 通过 FB 反馈连接的两个取样电阻，调整输出电压。具体计算公式为：Vout = VFB\*(1+R1/R2)

- PWM 电源需要随时检测输出电压是否达到要求的标准，避免出现输出电压过高或输出电压过低，当输出电压过压时，芯片内部采用 OVP（过压保护），当输出电压过低时，芯片内部采用 UVP(欠压保护)。
- PWM 电源需要随时检测输出电流。当出现过流事件时，芯片内部启用 OCP(过流保护)机制。
- 当出现输出异常时，芯片会启用内部的输出放电模式。此模式下，上管 G 极驱动信号被关断为 OV 低电平，下管 G 极驱动信号被驱动至 5V 高电平，此时上管截止，下管持续导通，输出滤波电容上储存的电荷通过下管迅速对地放电，输出电压关闭。
