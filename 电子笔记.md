## 电子元件

| 名称 | 特性                                                         | 作用                                   | 作用例子               |
| ---- | ------------------------------------------------------------ | -------------------------------------- | ---------------------- |
| 电感 | 通低频阻高频，通直流阻高频，电流不能突变                     | 滤波、抗高频干扰、储能                 | 大电感储能，小电感滤波 |
| 电容 | 充放电，通交流隔直流，通高频、阻低频、电容两端的电压不能突变 | 滤波、谐振、耦合                       |                        |
| 电阻 |                                                              | 上拉电阻、下拉电阻、保护电阻、热敏电阻 |                        |

## 电容

- 滤波-- 一个脚接地
- 谐振-- 晶振两个脚接电容到地，可以小幅度调整竞争的频率
- 耦合-- 串联在信号电路中，隔绝直流
