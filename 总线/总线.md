# 总线

- 总线(BUS)是计算机各种功能部件之间传送信息的线路，由导线组成。
- 按计算机所传输的信息种类分为
  | 种类 | 备注 |
  | -------- | ---- |
  | 数据总线 | |
  | 地址总线 | |
  | 控制总线 | |

## DMI 总线

- 在 Intel 芯片组中，连接 PCH 和 CPU 之间的通讯总线
- 用于传输除了显示信号以外的所有数据
- 共 4 组，(500 系列以后升级为 8 组),点对点双向传输，中间无任何元件

## 内存总线

- CPU 和内存之间的总线

## PEG 总线

- PEG （英文全称：PCI Express Graphics）总线：
- 连接 CPU 与 GPU
- 用于 CPU 对 GPU 的控制和信号传输
- 共 16 组，部分机型只采用其中 8 组或 4 组
- 每一组由 4 根线组成（一对发送，一对接收）
- 中间通过耦合电容传输；

## FDI 总线

- FDI（Flexible Display Interface:Intel 适应性显示接口）总线：
- 在 Intel 芯片组中，连接 PCH 和 CPU 之间的通讯总线
- 仅用于传输显示信号，点对点单向传输，中间无任何元件。

## CPU 输出的显示信号介绍

- CPU 输出的显示信号(eDP、DP、DDI 显示信号)
- 在 Intel 芯片组中，从第 4 代 CPU 开始逐渐采用 eDP、DP 和 DDI 显示信号。
- 1、eDP（Embedded DisplayPort）接口信号主要由 Main Link、AUXCH 与 HPD 三部分组成，用来传输各类型视频数据和音频数据；AUX CH 表示辅助通道，用于传输低带宽需求的数据，以及链路管理和设备控制信号;HPD 表示热插拔检测通道。
- 2、DP（DisplayPort）是一个由 PC 及芯片制造商联盟开发，视频电子标准协会(VESA)标准化的数字式视频接数据。此接口的设计是为了取代传统的 VGA、DVI 和 LVDS 接口。

* 3、DDI（Digital Display Interface）显示信号，其实这是 X86 CPU 内部的显示接口叫法，在它外边还有电路转换，最终合成我们会用到的 HDMI，DP 接口信号等等，如 CoffeeLake CPU 内部支持 3 个 DDI。

## PCH 的 PCIE 总线介绍

- PCIE，即 PCI-Express,是一种高速串行计算机扩展总线标准，是由英特尔在 2001 年提出的，PCIE 属于高速串行点对点双通道高带宽传输，有多种不同速度的接口模式，
  - 笔记本主板中，通常采用 PCIEx1 连接网卡、无线网卡、读卡器等设备，也可用于扩展其他外部设备。

## LPC/eSPI 总线介绍

- LPC（Low Pin Count 低脚位数量总线：在笔记本主板中，是 PCH 和 EC 之间的通讯总线，由供电、时钟、复位、帧周期和地址数据复合线组成
- eSPI(Enhanced Serial Peripheral Interface) 总线：由 Intel 在 2017 年提出，用以替代 LPC 总线。它复用了 4 线 SPI 总线的引脚定义，并加入了 Alert 和 Reset 引脚。

## eSPI 总线介绍

- SPI 总线是一种 4 线总线，用于 EC 或 PCH 读取 FLASH ROM 里面的程序

## SATA 总线

- SATA（Serial Advanced Technology Attachment）是一种串行总线，用于连接 SSD、HDD 和光盘驱动器。
- SATA 总线使用嵌入式时钟信号，具备了更强的纠错能力，与以往相比其最大的区别在于能对传输指令(不仅仅是数据)进行检查，如果发现错误会自动校正，这在很大程度上提高了数据传输的可靠性。串行接口还具有结构简单、支持热插拔的有点。
- SATA 总线由一对发送、一对接收信号组成，通过耦合电容传输

## USB 总线

- USB 总线是通用串行总线，可热插拔
- USB2.0 由 2 条数据线组成
- USB3.0 由 4 条数据线组成(一对发送，一对接收)

## SMBus

- System Management Bus 系统管理总线
- 两条线(SMB_CLK - 时钟线、SMB_DATA - 数据线)组成的串行总线。
- 也叫 I²C 总线用于笔记本电脑和台式电脑主板中的低速率通讯。
- 常用来控制主板上的设备(如控制充电电路给电池充电)(如 读取内存信息、温度信息、HDMI 接口设备 ID 等信息)

## CNVI 总线

- CNVI 是英特尔针对 WIFI 和蓝牙提供的新型专有连接口，可降低成本并简化其无线模块。
- 在 CNVI 中，网络适配器的大部分功能模块被整合进芯片组内部。
- 仅信号处理器，模拟和射频(RF)功能保留在外部可升级 CRF 伴射频模块上，该模块自 2019 年起采用 M.2 接口。
- CNVI 总线连接芯片组和 WIFI/蓝牙模块之间的总线，由 WT/WR 和 RGI/BRI 两组总线组成，其中 WT/WR 归 WIFI 使用，RGI/BRI 归蓝牙使用；
- CNVI 总线优点：不再占用芯片组提供的 PCI-E 通道（现在的无线网卡一般为 M.2 2230 E Key 规格，采用 PCI-Ex1 总线，蓝牙部分为 USB 总线）；推动主板厂商采用集成无线网卡。

## HDA 总线

- High Definition Audio 也叫高保真音频总线，俗称声卡总线，是电脑主板中的主流音频总线。用于连接声卡芯片和桥片之间，传输音频信号
- 组成
  - 1.HDA_BCLK：声卡总线时钟
  - 2.HDA_SDI0：声卡总线数据输入
  - 3.HDA_SDO: 声卡总线数据输出
  - 4.HDA_SYNC:声卡总线同步
  - 5.HDA_RST:声卡总线复位

## LPC 总线

- LPC（Low Pin Count 低脚位数量）总线，在笔记本主板中，是 PCH 和 EC 之间的通讯总线，由以下信号线组成：
  - 1.EC 的 LPC 总线供电，常见名字有：VCC、VCC3、VCC_LPC,电压为 3.3V，由外部电路提供
  - 2.LPC 总线时钟，常见名字有 LPCCLK、LCLK、PCICLK，频率为 33MHZ 或 24MHZ，由 PCH 送给 EC
  - 3.LPC 总线复位，常见名字有 LPCRST# LRESET# LRST# PCIRST#,电压为 3.3V，由 PCH 输出的 PLTRST#（平台复位）提供
  - 4.LPC 总线帧周期，常见名字有 LPC_FRAME#、LFRAME#,当这个信号有效时，指示开始或结束一次 LPC 总线数据传输，传输数据时可测波形，由 PCH 输出给 EC；
  - 5.地址、数据复合线，常见名字有 LAD0~LAD3、LPC_AD0~LPC_AD3,共 4 条线，用来传输 LPC 总线的地址和数据信息，传输数据时可测到波形，EC 和 PCH 之间双向通讯；
  - 6.第一阶段稳定时钟
    - 时钟必须先发出 33M 稳定方波
    - 时钟稳定后，LRESET# 拉高到 3.3V
    - 总线通讯 LFRAME# 拉低 通知总线上的从设备，和地址复合线同时产生
    - 复位信号在 几十毫秒 内发出

## ESPI 总线

- eSPI 总线，由 Intel 在 2017 年提出，用以替代 LPC 总线。它复用了 SPI 四倍速的引脚定义，并加入了 Alert 和 Reset 引脚：
  - 1.CLK：ESPI 总线时钟，类似于 LPC 总线时钟，时钟频率由程序定义(在苹果 A2159 机型中是 60M)

## SPI

- SPI 总线是一种 4 线总线用于 EC 或 PCH 读取 FLASH ROM 里面的程序
- SPI_CS0# 片选
- SPI_MISO 串行输出
- SPI_CLK 串行时钟
- SPI_MOSI 串行输入

BIOS 引脚

- 1- 片选
- 2- 串行数据输出
- 3-写保护
- 4-接地
- 5-串行数据输入
- 6-串行时钟
- 7-暂停、中断
- 8-供电
