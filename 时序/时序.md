# 时序

## Intel 100~400 系列芯片组的笔记本硬启动过程

1、 装入 3V 的纽扣电池后，产生 VCCRTC 给桥的 RTC 电路供电（4 大条件）
2、插上适配器或电池后，经过保护隔离电路，产生公共点
3、接着产生 EC 的待机供电，在待机供电正常后，EC 给晶振供电产生 EC 待机时钟（也有免晶振），待机供电延时产生 EC 待机复位(部分 EC 内部复位，如：KB9022/MEC1404)，EC 读取程序配置自身脚位。
4、\*如果 EC 检测到适配器，会自动开启桥的深度睡眠待机电压(VCCDSW_3P3),然后 EC 延时发出 DSW_PWROK 给桥，通知桥深度睡眠待机电压好
5、桥发出 SLP_SUS#,把深度睡眠待机电压转换为主待机电压(VCCPRIM_3P3、VCCPRIM_1P8 和 VCCPRIM_1P0),由主待机电压转换产生 RSMRST#给桥，通知桥主待机电压已经正常

4、\*如果 EC 检测到适配器，会自动发出开启信号去开启桥待机供电：VCCDSW_3P3、VCCPRIM_3P3、VCCPRIM_1P8 和 VCCPRIM_1P0,(有些机器需要按开关后才开启桥待机供电)
5、EC 延时发出待机电压好，同时发送给桥的 DSW_PWROK 和 RSMRST#引脚，通知桥待机电压已经正常(注：400 系列的桥，在以上条件正常后，桥会取 BIOS 配置脚位和 ESPI 总线，并发出 ESPI 总线复位：ESPI_RESET#)

6、按下开关，EC 收到开关信号后，延时发送一个高-低-高的开机信号给桥 PWRBTN#脚
7、桥发出高电平的 SLP_S5#、SLP_S4#、SLP_S3#、SLP_A#、SLP_LAN#。。。。。。
8、SLP_S5#或 SLP_S4#控制产生内存主供电 1.2V、内存 VPP 供电 2.5V、VCCST 供电 1V；SLP_S3#控制产生二级电压 3.3V、二级电压 5V、总线供电(VCCST_PWRGD)0.95V、VCCPLL_0C 1.2V、VCCPLL 1.0V 等；
9、VCCST 供电正常后，产生 VCCST_PWRGD 信号送给 CPU，CPU 发出 DDR_VTT_CNTL 信号控制产生内存 VTT 供电 0.6V
10、各供电正常后，产生 CPU 供电的开启信号，控制输出 VCCSA 供电 1.05V 和 CPU 核心供电(VBOOT 有的 1V 左右，有的 0V)
11、各供电正常后，桥的 24M 晶振起振，PG 汇总先后产生 PCH_PWROK 和 SYS_PWROK 送给桥
12、桥收到 PCH_PWROK 后，100~300 桥通过 SPI 总线读取 BIOS 中的 ME（主要读取：桥的引脚配置程序、MAC 地址、网卡 PHY 程序、ME 固件、时钟模块初始化）
13、桥发出各路时钟
14、桥发出 PROCPWRGD 给 CPU 打的 PROCPWRGD 脚
15、桥延时发出平台复位 PLTRST# 3.3V，桥再发出 CPU 复位 PLTRST_PROC#(PLTRST_CPU#)送给 CPU 的 RESET#脚
16、CPU 发出 SVID 波形给 CPU 供电芯片调整（开启）CPU 核心电压
17、CPU 供电正常，并得到复位后，通过 DMI 总线到桥，桥再通过 SPI 总线读取 BIOS，开始自检（跑码）
18、自检到内存时，桥通过 SMBUS 读取内存 SPD 信息后，桥发出内存复位 DRAM_RESEET#
19、CPU 再次发出 SVID 波形给 CPU 供电芯片，控制产生集显供电 VCCGT（0.7~1.3V 左右，部分机器的集显供电会出来一瞬间关闭）。

## 简化版

1、 装入 3V 纽扣电池，产生 VCCRTC 给桥 RTC 供电。
2、插上电池或适配器，经过保护隔离电路产生公共点。
3、接着产生 EC 的待机供电、待机时钟、待机复位、读取程序配置自身脚位。
4、检测到适配器，自动发出开启信号开启桥待机供电 VCCDSW_3P3 VCCPRIM_3P3 VCCPRIM_1P8 VCCPRIM_1P0
5、EC 延时发出待机电压好，送给桥 DSW_PWROK 和 RSMRST#引脚，通知桥待机电压正常。
6、按下开关，EC 收到开关信号后，延时发送一个高低高的开机信号给桥 PWRBTN#脚
7、桥发出高电平的 SLP_S5# 、 SLP_S4# 、 SLP_S3# 、 SLP_A#、 SLP_LAN#
8、SLP_S5# 或 SLP_S4 控制产生内存供电 1.2V、内存 VPP 供电 2.5V、VCCST 供电 1V；SLP_S3#
